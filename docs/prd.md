# SkyLog 产品需求文档

## 产品目标

SkyLog MVP 的目标是在移动端提供一个清晰、易用、结构化的飞行记录工具。用户可以在每次无人机飞行后快速保存基础信息，关联照片或视频，查看地图位置，并通过历史记录进行复盘。

第一版策略：

- 本地优先
- 不强制登录
- 不依赖云同步
- 离线可新增和查看记录
- 支持基础导出，便于备份和迁移

## 成功指标

- 用户可以在 2 分钟内完成一条基础飞行记录
- 首页能准确展示总飞行次数和总飞行时长
- 每条记录至少可以关联地点、日期、时长、设备和总结
- 地图页面能显示已记录的飞行点
- 用户可以通过日志列表快速找到历史飞行
- 原型测试中，用户无需说明即可理解主要操作路径

## 用户流程

### 新增飞行

1. 打开 App
2. 进入首页
3. 点击新增飞行
4. 填写地点、日期、时长、无人机型号、天气和风力
5. 选择飞行目的
6. 添加封面或素材
7. 输入飞行总结
8. 保存记录
9. 返回日志列表或进入详情页

### 回顾飞行

1. 进入飞行日志列表
2. 按时间查看历史记录
3. 点击某条记录
4. 查看完整飞行信息、地图位置、素材和总结
5. 根据记录进行复盘

### 地图足迹

1. 进入地图页面
2. 查看所有飞行地点
3. 点击地图点位
4. 查看该地点的飞行摘要
5. 进入详情页查看完整记录

## 页面需求

### 首页 Dashboard

页面目标：快速展示用户的飞行概况和最近记录。

显示内容：

- 最近一次飞行
- 总飞行次数
- 总飞行时长
- 本月飞行次数
- 最近上传素材
- 快捷新增按钮

交互：

- 点击最近飞行进入详情页
- 点击新增按钮进入新增飞行页面
- 点击统计卡片进入日志列表或统计页

### 新增飞行页面

页面目标：让用户以结构化方式记录一次飞行。

字段分组：

- 基础信息：飞行地点、日期、开始时间、飞行时长
- 设备信息：无人机型号、电池数量、电池备注
- 环境信息：天气、风力、温度、能见度
- 创作信息：飞行目的、镜头类型、拍摄说明
- 复盘信息：飞行总结、遇到的问题、下次改进
- 素材：封面图片、航拍照片、短视频

校验规则：

- 地点必填
- 日期必填
- 飞行时长必填，且必须大于 0
- 无人机型号建议填写
- 飞行总结可选

### 飞行日志列表

页面目标：按时间顺序展示全部飞行记录，帮助用户检索和回顾。

显示内容：

- 封面图
- 地点
- 日期
- 飞行时长
- 天气
- 无人机型号
- 简短总结

筛选方式：

- 按时间筛选
- 按无人机型号筛选
- 按地点关键词搜索
- 按天气筛选

### 飞行详情页

页面目标：完整展示一次飞行的所有信息。

显示内容：

- 封面图
- 地点和日期
- 地图位置
- 飞行时长
- 天气和风力
- 无人机型号
- 电池数量
- 飞行目的
- 素材画廊
- 飞行总结
- 问题记录
- 改进建议

交互：

- 编辑记录
- 删除记录
- 查看素材
- 打开地图定位
- 生成 AI 总结草稿，后续版本

### 地图页面

页面目标：用地图展示用户飞过的地点。

显示内容：

- 所有飞行点
- 当前选中飞行点摘要
- 飞行次数统计
- 时间范围筛选，后续版本

交互：

- 点击点位查看摘要
- 点击摘要进入详情页
- 根据时间范围筛选点位

### 个人页面

页面目标：展示用户飞行统计、设备和数据管理入口。

显示内容：

- 用户头像或昵称
- 总飞行次数
- 总飞行时长
- 常用无人机
- 我的无人机列表
- 数据导出入口
- 设置入口

## 非功能需求

- 本地记录打开速度应低于 1 秒
- 离线状态下可以查看已有记录
- 新增记录不依赖网络
- 第一版不要求用户登录
- 数据支持导出，便于备份和未来迁移
- 图片加载需要有占位状态
- 地图加载失败时显示清晰提示

## MVP 边界

第一版包括：

- 新增、编辑、删除飞行记录
- 飞行日志列表
- 飞行详情页
- 首页统计
- 封面图片和素材关联
- 地图点位或系统地图跳转
- 本地 SQLite 保存
- JSON 导出备份

第一版暂缓：

- 强制登录
- 实时云同步
- 视频云上传
- 自动剪辑
- 社区发布
- 自动读取全部厂商飞行数据
- App 直连 AI API

## 风险与应对

### 地图服务不稳定

MVP 优先保存经纬度并支持系统地图跳转，或使用轻量 App 内地图。Google Maps / Mapbox 可在后续阶段评估。

### 视频云存储成本高

MVP 先支持本地关联和缩略图展示，视频云上传放到后续阶段。

### 字段过多影响完成率

必填项控制在地点、日期、飞行时长。天气、设备、素材和总结作为可补充信息。

### AI 总结质量不稳定

AI 输出定位为可编辑草稿，并结合真实飞行数据和用户备注生成内容。
