# SkyLog Demo Script

## Demo Goal

Show how SkyLog helps a drone pilot record, review, and keep basic flight
records locally.

## Short Intro

SkyLog is an early mobile app prototype for drone pilots. It helps users prepare
before a flight and record each flight with location, date, duration, drone
model, weather, and reflection.

## Demo Flow

1. Open the Home screen.
2. Explain the dashboard:
   - total flights
   - flight time
   - latest flight
   - pre-flight checklist progress
   - recent logs
3. Open Checklist.
4. Check a few pre-flight safety items.
5. Open Add and show that the flight will save the current checklist status.
6. Open Logs.
7. Tap an existing flight record.
8. Show the detail page:
   - flight data
   - pre-flight checklist status
   - map location placeholder
   - flight summary
9. Return to Logs.
10. Open Add.
11. Create a sample flight record.
12. Save the record.
13. Show that the new record appears in Logs.
14. Stop and reopen the app.
15. Show that the record is still saved.
16. Delete the test record.
17. Open Profile and show the current version:
   - SkyLog v1.9
   - Fixed Web Beta Path
18. Show Deployment Readiness and Fixed Web Beta Path if the demo is about
   preparing the first tester link.

## What To Say At The End

This is not a finished public release. I am testing whether the flight logging
workflow makes sense and which fields are useful or annoying for drone users.

## Demo Length

Keep the demo under 5 minutes.
