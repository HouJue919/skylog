# SkyLog Tester Quick Start

SkyLog v2.3 keeps a short first-test path for people opening the beta link for
the first time.

## Live Beta

```text
https://houjue919.github.io/skylog/
```

## 60-Second Test

Ask a tester to:

1. Open Home and explain what they think SkyLog is for.
2. Open Checklist and complete the six items.
3. Open Add and create one sample flight.
4. Open Logs and find the sample flight.
5. Open Detail and check whether the saved checklist status makes sense.
6. Return to Profile and copy the feedback template.

## What To Watch

During the test, watch for:

- Whether the tester understands the app without a long explanation.
- Whether the bottom navigation feels obvious.
- Whether Add Flight asks for understandable information.
- Whether Logs and Detail connect clearly.
- Whether local data and beta limits are clear.

## Tester Safety Note

Testers should use sample data only. SkyLog stores records locally in the
current browser and is not a flight control or official safety app.
