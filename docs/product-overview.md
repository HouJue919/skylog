# SkyLog 产品说明

## 产品定位

SkyLog 是一款面向无人机爱好者、旅行航拍玩家和内容创作者的飞行日志 App。它帮助用户把每次飞行的地点、时间、天气、设备、素材和总结整理成可回顾的飞行档案。

核心定位：

> 把一次无人机飞行，从相册里的素材，变成可以搜索、复盘和再次使用的创作资产。

## 项目背景

消费级无人机让普通用户也能完成过去只有专业设备才能拍摄的航拍镜头。用户在旅行、城市探索、露营、户外运动和短视频创作中，越来越多地使用无人机记录空间、路线和场景。

飞行结束后，真正有价值的信息通常会分散在不同地方：

- 照片和视频保存在手机相册、SD 卡或硬盘中
- 飞行地点只靠照片定位或记忆回想
- 天气、风力和光线条件没有结构化记录
- 电池、设备、飞行问题和返航经验没有复盘
- 拍摄目的、可用镜头和后期剪辑思路没有和素材绑定

结果是用户保存了素材，却丢失了素材背后的飞行上下文。SkyLog 的出发点是把“素材保存”升级为“飞行复盘”，让每次飞行都能被记录、整理、回顾和改进。

## 目标用户

### 旅行航拍用户

他们在不同城市、景点、海边、山地和露营地飞行。核心需求是记录地点、回看路线、整理旅行素材，并形成自己的飞行足迹。

### 进阶无人机玩家

他们关心飞行表现、设备使用、电池情况、天气影响和飞行经验。核心需求是长期记录和复盘，避免重复犯错。

### 内容创作者

他们把无人机作为视频创作的一部分。核心需求是按项目管理素材，记录镜头类型、拍摄目的和可用片段。

### 新手飞手

他们需要记录练习过程、飞行问题和安全注意事项。核心需求是通过结构化复盘提高飞行能力。

## 现有工具的差距

| 工具 | 已经解决的问题 | 仍然缺少的部分 |
|---|---|---|
| DJI Fly / DJI GO | 飞控、设备连接、遥测记录、飞行日志、售后诊断 | 创作目的、素材筛选、个人复盘、跨项目整理 |
| 手机相册 | 保存照片和视频 | 无法系统记录天气、设备、风力和飞行经验 |
| 地图收藏 | 保存地点 | 与飞行数据、素材和总结脱节 |
| 备忘录 / Notion | 可以手动写总结 | 与照片、视频、经纬度和设备数据割裂 |
| 专业飞行管理软件 | 适合企业、航测、机队和合规管理 | 对个人航拍用户过重 |

SkyLog 的定位不是替代厂商 App，而是承接飞行之后的整理、创作复盘和长期回顾。

## 产品方案

SkyLog 把一次无人机飞行拆成六类信息：

- 基础信息：地点、日期、时间、飞行时长
- 环境信息：天气、风力、能见度、温度
- 设备信息：无人机型号、电池数量
- 创作信息：飞行目的、镜头类型、拍摄说明
- 素材信息：封面、照片、视频、片段说明
- 复盘信息：总结、问题、下次改进

用户通过三个核心视图回顾飞行：

- Dashboard：最近飞行、总飞行次数、总飞行时长、最近素材
- Flight Log：按时间查看、搜索和筛选所有记录
- Flight Map：查看飞过的地点和每个地点的飞行摘要

## 飞行记录生命周期

SkyLog 围绕一条记录逐步变完整的过程设计。

```text
草稿
  -> 本地保存
    -> 补充素材和地图
      -> 完成复盘
        -> 导出或长期归档
```

典型使用时序：

```text
飞行前：查看历史地点和注意事项
飞行后：用 1-2 分钟保存最小记录
整理时：补充照片、视频、天气和问题
剪辑前：按地点、设备、天气查找素材
复盘时：回看总结、地图足迹和改进建议
```

## 产品阶段

### 第一阶段：本地飞行日志

完成新增记录、日志列表、详情页、地图点位、素材关联和本地数据存储。用户无需登录，也可以离线使用。

### 第二阶段：备份与导出

加入 JSON / CSV 导出、飞行报告、图片路径管理和系统级文件备份方案。

### 第三阶段：厂商日志导入

支持用户主动导入 DJI Fly / DJI GO 等工具导出的 flight record 文件，自动生成飞行时长、轨迹、电池和告警摘要。

### 第四阶段：AI 复盘

通过服务端代理生成可编辑的飞行总结草稿，结合真实飞行数据、天气、素材说明和用户备注输出复盘建议。

### 第五阶段：作品集与创作管理

加入航拍项目、镜头标签、地图足迹分享、飞行报告和作品集页面。
