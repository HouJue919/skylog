# SkyLog Small Beta Feedback Plan

This document defines the v2.0 small beta feedback process.

## Goal

Use the fixed SkyLog web link to collect focused feedback before wider public
sharing.

Live beta:

```text
https://houjue919.github.io/skylog/
```

## Tester Mix

Start with 3-5 people:

- 2-3 regular users who can judge whether the app is clear and easy to use.
- 1-2 people interested in drones, photography, travel, or creative records.

The first testers do not all need to be drone pilots. At this stage, clarity,
trust, and usability matter as much as domain expertise.

## Test Flow

Ask each tester to:

1. Open the fixed web link.
2. Open Tester Quick Start in Profile.
3. Read Tester Instructions in Profile.
4. Complete the pre-flight checklist.
5. Add one sample flight record.
6. Search for the new record in Logs.
7. Open Detail and review the saved checklist status.
8. Copy the feedback template from Profile.
9. Send feedback after testing.

## Feedback To Record

For each tester, record:

- Tester type: regular user, photographer, traveler, drone user, or other.
- What they thought SkyLog was for.
- Where they got confused.
- Which feature felt most useful.
- Which feature felt unnecessary.
- Whether they trusted the data and beta explanations.
- One suggested improvement.

## Beta Rule

Do not treat v2.0 as a full public launch. Use this stage to learn what needs
to be clearer before wider sharing.
