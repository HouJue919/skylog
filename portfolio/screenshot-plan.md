# SkyLog 截图计划

这个文件用来规划之后放进作品集的 App 截图。

## 必备截图

1. Home Dashboard
   - 展示 SkyLog 标题、最近飞行和统计数据

2. Flight Logs
   - 展示飞行记录列表
   - 搜索框需要可见

3. Search Result
   - 搜索一个关键词，比如 `mountain`
   - 展示日志可以被检索

4. Add Flight
   - 展示新增飞行表单
   - 字段包括标题、地点、日期、时长、无人机、天气和总结

5. Flight Detail
   - 展示一次飞行的完整信息
   - 包括飞行数据、地图位置和总结

6. Edit Mode
   - 展示详情页进入编辑状态

7. Profile
   - 展示版本信息 `SkyLog v1.1`
   - 展示 Portfolio Polish 状态

## 截图要求

- 使用固定运行配置 `SkyLog Web (fixed storage)`
- 截图前先打开 Profile，点击 `Reset Demo Data`
- 使用系统恢复的 3 条干净样例记录
- 不要使用太随便的测试文字，比如 `aaa` 或 `test`
- 截图命名要清楚，例如：
  - `01-home-dashboard.png`
  - `02-flight-logs.png`
  - `03-search-results.png`
  - `04-add-flight.png`
  - `05-flight-detail.png`
  - `06-edit-mode.png`
  - `07-profile.png`
